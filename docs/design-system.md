# Datatem Design System

Uniform UI foundation for the combined data + shopping system. It is built on Tailwind CSS 4 tokens, Blade components and the Instrument Sans typeface, and it is used by every migrated page in both the storefront and the member area.

## 1. Brand and tokens

Tokens live in `resources/css/tokens.css` and are exported to Tailwind utilities through `@theme` (for example `bg-brand-navy`, `text-brand-navy`, `border-brand-yellow`, `rounded-card`, `rounded-control`).

| Token | Value | Usage |
|---|---|---|
| `brand-navy` | `#001534` | Header, primary text, feature surfaces, sidebar |
| `brand-navy-soft` | `#0B2550` | Secondary hover |
| `brand-yellow` | `#FFCC00` | Primary actions, header accent border |
| `brand-yellow-strong` | `#E6B800` | Primary hover |
| `brand-red` | `#E63946` | Non-text accents only |
| `brand-red-strong` | `#B0202D` | Text-bearing danger |
| `brand-red-strong-hover` | `#941B26` | Danger hover |
| `surface` / `surface-muted` | `#FFFFFF` / `#F4F4F4` | Page and secondary panels |
| `ink` / `muted` / `line` | `#0B0B0B` / `#5A6270` / `#E2E4E8` | Body text, secondary text, borders |
| `nav-muted` | `#D7DEEA` | Header navigation links on navy |

- Typography: Instrument Sans (bundled by Vite through `@fontsource-variable/instrument-sans`).
- Radii: controls `0.375rem`, cards `0.75rem`.
- Container: `75rem`, inline padding `1rem` (`.container-page`).
- Breakpoints: 40 / 48 / 64 / 80 / 96 rem.
- Rules: no gradients, no pill controls, no glow effects, no decorative emoji or Unicode.

Legacy bridge tokens (`primary-50` … `primary-900`, `mtn`, `airteltigo`, `telecel`) exist only so pre-migration r2b pages render in the brand palette until their phase restyles them. New work uses `brand-*` tokens.

## 3. Navigation model

- Desktop member area: fixed left sidebar grouped as Overview (Dashboard, Shop, Buy data), Orders (Orders, Wallet), Earnings (Referral, Reseller) and Account (Notifications, Profile, Support).
- Desktop public area: top navigation (Home, Shop, Bundles, Stores, Support).
- Mobile everywhere: bottom navigation with Home, Shop, Bundles and Account; the public cart link appears in the header once the shop module ships.
- Navigation items are generated by `App\Support\Navigation` so both shells stay in sync.

## 4. Accessibility

- All text/background pairs meet WCAG AA 4.5:1; asserted by `tests/Unit/DesignTokensTest.php`.
- Visible 2px focus outlines on every interactive element.
- Skip link targets `#main-content`; navigation landmarks have accessible names.
- The alert dialog is `role="dialog"` with `aria-modal` and a labelled title.
- Motion respects `prefers-reduced-motion`.

## 5. Build and preview

```powershell
$env:PATH = 'C:\laragon\bin\nodejs\node-v22;' + $env:PATH
npm install
npm run build
php artisan serve
```

`GET /design-system` renders the component preview outside production. Migrated pages must not load external CDNs (`cdn.tailwindcss.com`, `unpkg.com`, `fonts.googleapis.com`); Alpine and fonts are bundled.

Standalone pages `storefront` and `spin-preview` still carry their original CDNs until their phases (3 and 4) migrate them.
