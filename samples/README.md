# Refer2Bundle API V1 - Code Samples

This directory contains sample code in multiple programming languages demonstrating how to use the Refer2Bundle API.

## Available Samples

### Get Balance
- `balance/balance.php` - PHP example
- `balance/balance.py` - Python example
- `balance/balance.js` - JavaScript (browser) example
- `balance/balance_node.js` - Node.js example
- `balance/Balance.java` - Java example
- `balance/Balance.cs` - C# example
- `balance/balance.go` - Go example
- `balance/balance.rb` - Ruby example
- `balance/balance.sh` - Bash/cURL example

### Create Order
- `order/order.php` - PHP example
- `order/order.py` - Python example
- `order/order.js` - JavaScript (browser) example
- `order/order_node.js` - Node.js example
- `order/order.sh` - Bash/cURL example

## Usage

1. Replace `your_api_key_here` with your actual API key
2. Update the API URL if using a different domain
3. Run the sample code

## Requirements

### PHP
- PHP 7.4+ with cURL extension

### Python
- Python 3.6+
- `requests` library: `pip install requests`

### Node.js
- Node.js 12+
- `axios` library: `npm install axios`

### Java
- Java 8+
- `org.json` library

### C#
- .NET Core 3.1+
- `Newtonsoft.Json` NuGet package

### Go
- Go 1.16+

### Ruby
- Ruby 2.7+
- Standard libraries only

### Bash
- Bash 4+
- `curl` command
- `jq` (optional, for JSON parsing)

## API Base URL

Default: `https://refer2bundle.org/api/v1`

Update the `api_url` variable in each sample if using a different domain.

## Documentation

For complete API documentation, visit: `/api/v1/docs.php`
